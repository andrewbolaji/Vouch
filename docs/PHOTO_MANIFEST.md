# Photograph manifest

One line per file in `assets/demo/`. This exists because a claim that
lives only in someone's recollection becomes untrue by default the
moment they stop being the one asked, and the provenance of these
files was recorded nowhere before 2026-08-17.

**Nothing in this set may be uploaded to Firebase Storage until its
Source and Permission columns are filled in.** See
`docs/PHOTO_PROVENANCE_MEASUREMENT.md` for how the metadata columns
were produced and what they do and do not prove.

Columns:

- **Metadata** is measured, not asserted. It is the value of
  `exif:UserComment` in the file's XMP packet.
- **Source** is where the image came from. Andrew fills this in. Free
  text, but it has to name a thing: "own camera", "sent by the
  restaurant, email 2026-05-04", "Instagram @handle", "restaurant
  website".
- **Permission** is what allows Vouch to publish it: "own work",
  "written permission from X on DATE", "none".
- **Renders today** marks the 6 files that a real restaurant document
  currently resolves. Those are the ones that block launch; the other
  53 can be answered later or deleted.
